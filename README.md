# AI問い合わせアシスタント

StreamlitとGoogle Gemini APIを組み合わせた、業務向けのLLMチャットアプリケーションです。
生成AIを単に導入するだけでなく、実務運用における「コスト管理」「セキュリティ」「メンテナンス性」を考慮した設計を施しています。

## 主な機能と設計の特徴

### 1. 保守フリー（最新モデル自動追従設計）

固定のモデル名をハードコーディングせず、起動時にGoogleのAPIから現在利用可能なモデルリストを動的にリアルタイム取得します。将来的に新モデルがリリースされた際も、ソースコードを一切書き換えることなく、自動的に選択肢へと反映される「メンテナンスフリー」な設計です。

### 2. インタラクティブなLLMチューニング機能

非エンジニアの運用者でも、ビジネス要件に合わせてAIの挙動をノーコードで最適化できるよう、以下のハイパーパラメータをUI化しています。

- ペルソナ（システムプロンプト）動的切り替え: 役割に応じたプロンプトの検証が可能。
- Temperature（温度値）調整: 厳密なFAQ対応からクリエイティブなアイデア出しまで対応。
- 最大出力トークン数制御: 1回あたりの応答長さを制限し、APIの無駄なコスト消費を防止。

### 3. メモリベースのセキュリティ設計（WebLLM風アプローチ）

ユーザーが入力したAPIキーは、ブラウザのセッションメモリ（`st.session_state`）内でのみ一時的に保持されます。サーバーやデータベースへの保存・送信処理は一切行われないため、不特定多数がアクセスする環境でも安全に運用が可能です。

## 起動方法（ローカル環境）

### 1. リポジトリのクローン

```bash
git clone https://github.com/あなたのユーザー名/リポジトリ名.git
cd リポジトリ名
```

### 2. 必要なライブラリのインストール

```bash
Bash
pip install -r requirements.txt
```

### 3. アプリケーションの起動

```bash
streamlit run app.py
```

## 免責事項・ライセンス

本アプリケーションで入力されたAPIキーおよびチャット内容は、開発者側のサーバーには一切蓄積されません。Google Gemini APIの利用規約および無料枠の制限に従って動作します。
